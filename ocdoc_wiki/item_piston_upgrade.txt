Piston Upgrade
====
{{:items:upgradepiston.png?nolink&128}}

Provides the [[component:piston|piston component]].

The piston upgrade can be used to push blocks in the world, in a pretty much identical manner to the way vanilla pistons push blocks.
  
The Piston Upgrade is crafted using the following recipe:
  * 4 x Iron Ingot
  * 2 x Stick
  * 1 x Piston
  * 1 x [[item:materials|Printed Circuit Board]]
  * 1 x [[item:materials|Microchip (Tier 1)]]
