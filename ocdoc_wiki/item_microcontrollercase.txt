Microcontroller Case
=======================
{{:items:microcontrollercase0.png?nolink&128|}} {{:items:microcontrollercase1.png?nolink&128|}}

This item is used in an [[block:assembler|Assembler]] to build [[block:microcontroller|Microcontrollers]], which are essentially cheaper and minimalistic computers, intended for special use-cases, such as redstone control.  

Tier 1
--------
The Microcontroller case (Tier 1) can house the following components (up to the specified tier):
  * 1 x [[item:cpu|CPU (Tier 1)]]
  * 1 x [[item:memory|Memory (Tier 1)]]
  * 1 x [[item:eeprom|EEPROM]]
  * 2 x Expansion card (Tier 1)
  * 1 x Upgrade (Tier 2)

The Microcontroller Case (Tier 1) is crafted using the following recipe:
  * 4 x Iron nugget/oreberry (with Tinker's Construct)
  * 2 x Redstone dust
  * 1 x Chest
  * 1 x [[item:materials|Printed Circuit Board]]
  * 1 x [[item:materials|Microchip (Tier 1)]]
{{:recipes:items:t1microcase.png?nolink&200}}

Tier 2
--------
The Microcontroller case (Tier 2) can house the following components (up to the specified tier):
  * 1 x [[item:cpu|CPU (Tier 1)]]
  * 2 x [[item:memory|Memory (Tier 1)]]
  * 1 x [[item:eeprom|EEPROM]]
  * 1 x Expansion card (Tier 1)
  * 1 x Expansion card (Tier 2)
  * 1 x Upgrade (Tier 3)

The Microcontroller case (Tier 2) is crafted using the following recipe:
  * 4 x Gold nugget/oreberry (with Tinker's Construct)
  * 2 x Block of Redstone
  * 1 x Chest
  * 1 x [[item:materials|Printed Circuit Board]]
  * 1 x [[item:materials|Microchip (Tier 3)]]
{{:recipes:items:t2microcase.png?nolink&200}}

Tier 4 (Creative)
----------------------

The Creative Microcontroller case can house the following components (up to the specified tier):
  * 1 x [[item:cpu|CPU (Tier 3)]]
  * 3 x Expansion slot (Tier 3)
  * 2 x [[item:memory|Memory (Tier 3)]]
  * 1 x [[item:eeprom|EEPROM]]
  * 9 x Upgrades (Tier 3)
