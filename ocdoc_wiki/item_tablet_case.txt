Tablet Case
===================

{{:items:t1tabletcase.png?nolink&128}}{{:items:t2tabletcase.png?nolink&128}}{{:items:t4tabletcase.png?nolink&128}}

Tablet cases are used to build [[item:tablet|tablets]], which are handheld computers. A creative tablet case also exists for playing around with different configurations in Creative mode. 

Tablets take a limited subset of upgrades, unlike Robots. Tablets also have access to only one upgrade or card container slot (Tier 2 and Creative).

Tier 1 
--------

The Tier 1 Tablet case supports the following components (tiers indicate the maximum tier of component the case can take):
  * 1 x [[item:cpu|CPU (tier 2)]]
  * 2 x [[item:memory|Memory (tier 2)]]
  * 1 x [[item:hard_disk_drive|HDD (tier 2)]]
  * 2 x Expansion slot (Tier 2)
  * 1 x [[item:eeprom|EEPROM]]
  * 1 x Upgrade (Tier 1)
  * 1 x Upgrade (Tier 2)
  * 1 x Upgrade (Tier 3)

The Tier 1 Tablet case can be crafted using the following recipe:
  * 1 x [[block:screen|Screen (Tier 2)]]
  * 4 x Gold ingot
  * 1 x Button
  * 1 x [[item:component_bus|Component Bus (Tier 1)]]
  * 1 x [[item:materials|Printed Circuit Board]]
  * 1 x [[item:materials|Microchip (Tier 3)]]
{{:recipes:items:t1tabletcase.png?nolink&200}}

Tier 2 
--------

The Tier 2 Tablet case supports the following components:
  * 1 x [[item:cpu|CPU (tier 3)]]
  * 2 x [[item:memory|Memory (tier 2)]]
  * 1 x [[item:hard_disk_drive|HDD (tier 2)]]
  * 1 x Expansion slot (Tier 2)
  * 1 x Expansion slot (Tier 3)
  * 1 x [[item:eeprom|EEPROM]]
  * 2 x Upgrade (Tier 2)
  * 1 x Upgrade (Tier 3)
  * 1 x Upgrade/Card container (Tier 2)

The Tier 2 Tablet case can be crafted using the following recipe:
  * 1 x [[block:screen|Screen (Tier 2)]]
  * 2 x Gold ingot
  * 1 x Button
  * 1 x [[item:component_bus|Component Bus (Tier 3)]]
  * 1 x [[item:materials|Printed Circuit Board]]
  * 1 x [[item:materials|Microchip (Tier 3)]]
  * 2 x [[item:materials|Microchip (Tier 2)]]
{{:recipes:items:t2tabletcase.png?nolink&200}}

Tier 4 (Creative) 
--------

The creative Tablet case supports the following components:
  * 1 x [[item:cpu|CPU (tier 3)]]
  * 2 x [[item:memory|Memory (tier 3)]]
  * 1 x [[item:hard_disk_drive|HDD (tier 3)]]
  * 3 x Expansion slot (Tier 3)
  * 1 x [[item:eeprom|EEPROM]]
  * 9 x Upgrade (Tier 3)
  * 1 x Upgrade/Card container (Tier 3)
