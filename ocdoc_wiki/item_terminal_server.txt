Terminal Server
==============
{{:items:terminalserver.png?nolink&128|}}

The Terminal Server can be bound to [[item:terminal|remote terminals]] which provides a remote accessible tier 3 screen and keyboard. Terminal servers are blades that fit in [[block:server_rack|racks]], and need to share a configured side (see the rack gui) with a server blade to be connected. Terminal servers have a range limit equal to a tier 2 wireless card.
  
The Terminal Server is crafted using the following recipe:
  * 4 x Obsidian Block
  * 1 x [[item:wireless_network_card|Wireless Network Card (Tier 2)]]
  * 1 x [[item:materials|Microchip (Tier 2)]]
  * 1 x Printed Circuit Board
