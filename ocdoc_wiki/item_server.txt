Server
======
{{:items:server1.png?nolink&128|}} {{:items:server2.png?nolink&128|}} {{:items:server3.png?nolink&128|}}

A Server can contain components like a Computer Case. Open a Server by having it selected in your hotbar and rightclicking (like opening an Ender Pouch, for example). A configured server can be placed into a [[block:rack|server rack]], where it can then be powered on and perform like a normal computer. Servers can be controlled using a Remote Terminal, which will act like a portable Screen+Keyboard combo for the server.

The Server (Tier 1) can be crafted using the following recipe:
  * 4 x Obsidian
  * 1 x [[item:memory|Memory (Tier 2.5)]]
  * 1 x [[item:materials|Microchip (Tier 2)]]
  * 2 x [[item:materials|Microchip (Tier 1)]]
  * 1 x [[item:materials|Printed Circuit Board]]
{{:recipes:items:t1server.png?nolink&200}}

The Server (Tier 2) can be crafted using the following recipe:
  * 4 x Obsidian
  * 1 x [[item:memory|Memory (Tier 3)]]
  * 1 x [[item:materials|Microchip (Tier 3)]]
  * 2 x [[item:materials|Microchip (Tier 2)]]
  * 1 x [[item:materials|Printed Circuit Board]]
{{:recipes:items:t2server.png?nolink&200}}

The Server (Tier 3) can be crafted using the following recipe:
  * 4 x Obsidian
  * 1 x [[item:memory|Memory (Tier 3.5)]]
  * 3 x [[item:materials|Microchip (Tier 3)]]
  * 1 x [[item:materials|Printed Circuit Board]]
{{:recipes:items:t3server.png?nolink&200}}
