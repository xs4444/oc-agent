Component: Robot
----
This component is provided by the [[block:robot|Robot]]. The functions below can be called in the Lua interpreter using `=component.robot.function()`. To make robot function calls more intuitive, a [[api:robot|Robot API]] exists as a wrapper around the component functions, providing additional functionality (which is summarized in the API page).
