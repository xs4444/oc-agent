Network Card
===========
{{:items:lan_card.png?nolink&128|}}

Allows distant computers connected by other blocks (such as cable) to communicate by sending messages to each other.

See the [[component:modem|network card component's API]] to see how to send and receive messages.

The Network Card is crafted using the following recipe:
  * 1 x [[block:cable|Cable]]
  * 1 x [[item:materials|Microchip (Tier 1)]]
  * 1 x [[item:materials|Card Base]]
