Scrench
=======

The Scrench (patent pending) is a combination Screwdriver and Wrench, and behaves similar to other tools provided by various mods (such as BuildCraft, IndustrialCraft, etc). It provides similar functionality such as rotating blocks, removing blocks without having to break the block, etc. 

The Scrench can be crafted using the following recipe:
  * 3 x Iron Ingot
  * 1 x [[item:materials|Microchip (tier 2)]]
