# Motion Sensor
![](../media/blocks/motion_sensor.png)

Allows detecting movement of nearby living entities, as long as a direct line of sight is given. Sensitivity can be configured via [its API](../component/motion_sensor.md).

*Added in OC 1.3.2.*

The Motion Sensor is crafted using the following recipe:
  * 4 x Gold ingot
  * 3 x Daylight Sensor
  * 1 x [CPU (Tier 2)](../item/cpu.md)
  * 1 x [Printed Circuit Board](../item/materials.md)
