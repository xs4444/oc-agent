# OpenOS Floppy Disk
The OpenOS floppy disk is a craftable [loot disk](loot_disks.md) that allows OpenOS to be run or installed on a [HDD](hard_disk_drive.md)

![](../media/recipes/items/openos.png)

It can be crafted by combining an [OpenComputers Manual](manual.md) and a [Floppy Disk](floppy_disk.md) in a crafting table.

You can install it to a [HDD](hard_disk_drive.md) by typing "install" and following the on screen instructions. [Here](../openos.md) is a more detailed explanation of its install process.
